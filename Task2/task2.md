## Task: Shell

今天学习了 Linux 和 Shell 的基本使用。

### 常用命令

- `pwd`：查看当前所在目录
- `ls`：查看当前目录中的文件
- `cd`：切换目录
- `mkdir`：创建目录
- `cat`：查看文件内容
- `rm`：删除文件

### 我的第一个 Shell 脚本

```bash
#!/bin/bash
echo "Hello RTS!"
pwd
ls
```

运行脚本：

```bash
./task1.sh
```
